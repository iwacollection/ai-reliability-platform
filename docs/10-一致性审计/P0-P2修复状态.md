## P1：Action Fingerprint

状态：**模型层已完成，Runtime Gate 仍需最终接线**。

指纹覆盖完整 ActionPlan，并使用稳定 JSON + SHA-256。

```text

```

Approval 不能被理解为“批准了这个动作类型”，而是批准了**这一份精确 ActionPlan**。
